Exemplo prático de separação entre HTML e CSS

O que é HTML?

HTML é a linguagem de marcação que define a estrutura e o conteúdo de uma página web.

O que é CSS?

CSS é o que dá estilo visual (cores, fontes, espaçamentos e layout) aos elementos estruturados pelo HTML.
